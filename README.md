# Concept Reminder

This repository is my personal reminder on some concepts — short notes, cheatsheets, and saved references I collect while working across data science, machine learning, and AI engineering.

Whenever something turns out to be non-trivial to figure out — a definition, a comparison, a formula, a process — I save it here so I don't have to re-learn or re-google it later.

## What these files are

- `.txt` and `.md` files are my own quick notes written as reminders — short, sometimes rough, often in a "compare X vs Y" style.
- `.pdf`, image, and slide files are saved references that I want to keep within reach.

The file names are intentionally descriptive, so a folder listing already works as an index.

## Finding things

- Browse by topic folder above — every file was gone through and filed by its primary topic.
- GitHub's search or `Ctrl+F` after pressing <kbd>.</kbd> (which opens github.dev here) is usually the fastest way to find a specific concept.
